## Teaser Post Template

```text
React Dependency Injection Without Containers
```

Body:

```md
Dependency injection in React does not have to mean containers, decorators, or enterprise ceremony.

Most of the time, the useful version is smaller:

1. Build concrete services near the application boundary.
2. Pass capabilities through props or scoped context.
3. Keep feature code independent from API clients, storage, analytics, and state libraries.
4. Add containers only when object graph assembly becomes the real problem.

I wrote a full breakdown with composition root examples, props vs context vs container trade-offs, and a production checklist.
```
